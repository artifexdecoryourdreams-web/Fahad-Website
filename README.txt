MD FAHAD MULTI-PAGE PORTFOLIO

HOW TO USE
1. Extract this ZIP file.
2. Open index.html in your browser.
3. Edit the page content in each HTML file.
4. Edit style.css to change colors, spacing and design.
5. Edit script.js to change the contact email.

PAGES
- index.html: Home
- about.html: About Me
- skills.html: Skills and skill categories
- experience.html: Experience timeline
- projects.html: Project categories with working filters
- gallery.html: Gallery categories with working filters
- contact.html: Social links and contact form

IMPORTANT
- Replace your-email@example.com in script.js with your email.
- Replace the sample social media URLs with your own profile links.
- Contact form uses the visitor's email application (mailto); it is not a server-backed form.
- Add your own project descriptions and photos where indicated.
